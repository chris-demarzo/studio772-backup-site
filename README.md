# Max Encrypted Backup identity site

Public identity and policy pages for the private, owner-operated Google Drive backup utility at `backup.studio772.com`.

## Verify

```sh
npm test
```

## Publish

The repository is a static site. Its production domain is declared in `CNAME`. Google OAuth branding uses:

- Homepage: `https://backup.studio772.com/`
- Privacy policy: `https://backup.studio772.com/privacy/`
- Terms of use: `https://backup.studio772.com/terms/`
- Authorized domain: `studio772.com`
- Support/developer email: `chris@studio772.com`

No credentials, backup data, OAuth tokens, analytics, forms, or runtime scripts belong in this repository.

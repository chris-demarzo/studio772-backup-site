Max Encrypted Backup

A private, owner-operated utility that transfers encrypted backup data from the owner’s server to the owner’s Google Drive account.

No public registration or user accounts

What this application does

Encrypted before upload

Backup contents are encrypted on the owner’s server before they are sent to Google Drive.

Owner-authorized access

Google OAuth authorizes the backup software to access the owner’s Drive for backup storage and maintenance.

Not a public service

This utility is not offered to customers, does not accept public sign-ups, and does not advertise using Google user data.

Data use at a glance

  • Google Drive access is used only to operate and maintain the owner’s encrypted off-site backups.
  • OAuth credentials remain on systems controlled by the owner.
  • Google user data is not sold, shared for advertising, or used to train models.
  • Access can be revoked from the owner’s Google Account at any time.

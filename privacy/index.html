Privacy Policy

Max Encrypted Backup is a private, owner-operated utility. It has no public registration and is used only by its owner to maintain encrypted off-site backups in the owner’s Google Drive account.

Google data accessed

The utility uses Google OAuth to authorize backup software to access the owner’s Google Drive. The configured Google Drive permission can allow the software to view, create, update, and delete Drive files. The operator uses that access only to create, verify, retain, and remove the owner’s encrypted backup repository objects.

How data is handled

Backup contents are encrypted on the owner’s server before upload. Google receives encrypted backup objects and the technical metadata needed to store them. OAuth credentials and backup encryption keys remain on systems controlled by the owner and are not published by this website.

Collection and sharing

This website has no forms, analytics, advertising, cookies, or public accounts. The utility does not sell Google user data, does not share it with advertisers or data brokers, and does not use it for advertising, profiling, or model training. Data is disclosed only when required by law or when necessary to protect the owner’s systems and rights.

Retention and deletion

Encrypted backup objects are retained according to the owner’s backup retention policy and are deleted when snapshots expire or the repository is retired. Server and provider security logs may be retained for limited operational and abuse-prevention purposes.

Security

The operator uses encryption before transfer, access controls, and restricted local credential storage. No method of storage or transmission can be guaranteed completely secure.

Control and revocation

The owner can revoke this utility’s Google access at any time from the security settings of the connected Google Account. Revocation prevents future Google Drive backup operations until access is authorized again. Backup objects already stored in Drive can be deleted directly by the owner.
